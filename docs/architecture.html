Request Lifecycle

1
User interacts with a Vue view
Selects filters in FilterBar.vue (warehouse, category, status, month).
2
View calls the API client
e.g. api.getInventory(filters) from client/src/api.js.
GET http://localhost:8001/api/inventory?warehouse=W01&category=Electronics
3
FastAPI route applies filters
Endpoint in server/main.py calls apply_filters() against the loaded JSON dataset.
4
Pydantic validates the response
Items shaped against models like InventoryItem, Order, BacklogItem.
5
Vue updates reactive state
Raw data lands in refs (allOrders, inventoryItems); derived values are computed properties; template re-renders.
